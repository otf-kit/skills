# Contributing to OTF Agent Skills

## Report a problem

Search [existing issues](https://github.com/otf-kit/skills/issues). Name the skill, explain the task and unexpected guidance, and include a small example with private data removed.

## Propose a change

```bash
git clone https://github.com/otf-kit/skills.git
cd skills
```

Create a branch from `main`. Keep edits focused on the relevant `skills/<name>/SKILL.md` and its supporting files. In your pull request, explain the behavior change and show a short example of the revised guidance. A maintainer reviews changes before merge.
